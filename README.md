# Tesis Orozco MCD 25
## Sobre el proyecto
Este proyecto de tesis de maestría en el Instituto Tecnológico de Buenos Aires buscará contribuir a la ciencia de datos en torno al análisis de los daños producidos como consecuencia de la inundación ocurrida en Bahía Blanca, Argentina, el 7 de marzo de 2025 a través de la aplicación de diferentes técnicas de análisis de imágenes satelitales. Para ello, se realizará una comparación entre diferentes métodos de Machine Learning y se arribará a conclusiones que servirán para mejorar el proceso decisorio en entornos de emergencias.
