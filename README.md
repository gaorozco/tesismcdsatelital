# Tesis Orozco MCD 25
## Sobre el proyecto
Este proyecto de tesis de maestría en el Instituto Tecnológico de Buenos Aires busca contribuir a la ciencia de datos en torno al análisis de los daños producidos como consecuencia de la inundación ocurrida en Bahía Blanca, Argentina, el 7 de marzo de 2025 a través de la aplicación del análisis de imágenes satelitales. Para ello, se realiza una comparación entre 3 métodos de Machine Learning y se arriba a conclusiones que servirán para mejorar el proceso decisorio en entornos de emergencias. 

### Créditos: https://dataspace.copernicus.eu/
